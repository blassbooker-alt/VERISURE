# Fortalfy v14 — revisão funcional

1. Extraia o ZIP.
2. Abra `fortalfy_v10/index.html` num navegador atualizado.
3. Cadastre uma conta de demonstração e teste os atalhos para academias, profissionais e cursos.
4. Teste o feed e as ações locais com a indicação de demonstração.
5. Leia `RELATORIO_AUDITORIA_V14.md` para ver as limitações que ainda exigem backend.

**Atenção:** esta versão não é um sistema de produção. Não use dados sensíveis, credenciais reutilizadas, pagamentos reais ou compromissos reais. As ações locais não sincronizam entre dispositivos.
