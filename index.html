Perguntas frequentes

Antes de começar, saiba como funciona.

Informações transparentes para uma decisão consciente.

Os planos já estão disponíveis para contratação?

Os valores exibidos são uma proposta inicial. A contratação só deve ser aberta após confirmar parceiros, benefícios, limites de utilização, atendimento e condições comerciais.

Posso acessar qualquer academia ou restaurante?

Não automaticamente. O acesso dependerá da rede de parceiros ativos, das cidades atendidas e das regras específicas de cada benefício.

As informações nutricionais são garantidas?

Os dados deverão ser fornecidos ou validados pelos estabelecimentos responsáveis. A interface de demonstração usa exemplos ilustrativos e não substitui orientação nutricional.

Como funcionam consultas e agendamentos?

É possível testar uma solicitação demonstrativa, salva somente neste navegador. Ela não chega a um profissional, não reserva horário e não confirma atendimento.

Como uma empresa pode se tornar parceira?

Use o formulário para cadastrar interesse comercial. O envio fica salvo neste dispositivo e não chega à equipe comercial.

O site já recebe pagamentos ou pedidos?

Não. Esta versão é um protótipo navegável. Não insira dados bancários ou senhas reais; pagamentos, pedidos, autenticação e banco de dados ainda precisam ser integrados e testados.
