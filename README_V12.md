# Fortalfy v12 — interface de aplicativo

## O que mudou
- Painel autenticado com botão de foto no canto superior direito.
- Menu da conta com Perfil, Carteira/Pagamentos, Configurações, Pedidos, Agendamentos e Sair.
- Menus contextuais para contas de empresas/parceiros e profissionais.
- Faixa publicitária com fotografias de estilo editorial para academia e alimentação.
- Atalhos diretos para feed, profissionais, academias, comida e agendamentos.
- Fotos reais de banco de imagens via Unsplash em cards de academia e alimentação.
- Layout responsivo para desktop e celular.

## Testar
1. Extraia o ZIP.
2. Abra `fortalfy_v10/index.html` em navegador atualizado.
3. Crie uma conta de demonstração.
4. No painel, clique na foto no canto superior direito para abrir as opções.
5. Teste perfil, pagamentos/carteira, configurações, pedidos, agendamentos e sair.
6. Para ver as opções de empresa, crie uma conta com perfil Restaurante, Academia ou Marca/Loja parceira. Para ver opções profissionais, crie Personal ou Nutricionista.

## Limites importantes
Esta continua sendo uma demonstração front-end. A autenticação, os cadastros, a carteira, pedidos e agendamentos usam armazenamento local e não são sincronizados entre aparelhos. Não há pagamento real, pedidos enviados a restaurantes, agenda compartilhada ou validação oficial de empresas. As fotografias são imagens editoriais externas do Unsplash e não devem ser interpretadas como fotos de parceiros reais da Fortalfy. Os perfis e selos de demonstração não representam verificações reais. Para produção, conectar autenticação segura, banco de dados, armazenamento de imagens e permissões administrativas.
